PAPER TRACK — STEROWANIE KLIKNIĘCIAMI

1. Otwórz PaperTrack.html dwuklikiem w Chrome lub Edge.
2. Wybierz Nowa gra albo Kampania.
3. Kliknij czerwony punkt START.
4. Kliknij sąsiedni podświetlony punkt: prosto albo po przekątnej. Powstanie jeden odcinek.
5. Klikaj następne sąsiednie punkty. Jeden klik = jedna kratka. Dalsze punkty są odrzucane.

Nie przeciągaj myszy. Na telefonie dotykaj kolejnych punktów. Przyciskiem + powiększysz planszę.
Cofnij usuwa ostatni odcinek, Cofnij 5 usuwa kilka, Restart rozpoczyna próbę od nowa.

Gra HTML działa bez internetu, bez Node.js i bez serwera.
ZIP zawiera także pełne źródła w folderze kod-zrodlowy. W tym folderze: npm ci, następnie npm run dev (Node.js 24).
Instalacja PWA na iPhone/iPad wymaga wersji hostowanej przez HTTPS.
