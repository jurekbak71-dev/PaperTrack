PAPER TRACK — GOTOWA GRA

1. Rozpakuj ZIP.
2. Otwórz PaperTrack.html w Chrome lub Edge (dwuklik).
3. Wybierz Nowa gra lub Kampania.

Nie trzeba instalować Node.js ani uruchamiać serwera. Cała gra i generator są w pliku HTML i działają bez internetu.

Folder kod-zrodlowy zawiera pełny projekt TypeScript, testy, README i workflow GitHub Pages. Aby rozwijać projekt: zainstaluj Node.js 24, wykonaj npm ci i npm run dev w tym folderze.

Wersja jednoplikowa służy do lokalnego grania. Instalacja PWA na iPhone/iPad wymaga wersji hostowanej przez HTTPS (instrukcje GitHub Pages w README).
